# 群星传 · 危机纪元

**从一颗蓝色星球，写下文明的下一页。**

[开始游戏](https://bunwright.github.io/legendofuni-remake/) · [原作与资源来源](CREDITS.md)

《刘慈欣群星传》的浏览器重制版。保留原作的年度经营、科技谱系、人物、星际战争、外交理论与剧情对白，以 Three.js 实时宇宙重新呈现。无需安装、账号或后端，存档保存在本机浏览器。

## 游戏内容

- 四层星域、209 个天体，从太阳系走向银河。
- 七条科技谱系、51 项科技，统筹矿藏、工业、文化与科研人口。
- 28 位人物、11 个异星文明、10 种武器，殖民建设与舰队调动。
- 战术目标选择、先手交锋、消耗武器、指挥官技能与永久战损。
- 基于宇宙社会学的外交应答，可通过结盟、征服或混合路线获胜。
- 原作 13 个剧情事件、8 个随机事件，以及完整结局对白。
- 三维星球、光晕、轨道、舰队与原作音乐；支持触屏、低画质、减少动画和无 WebGL 回退。

### 从地球出发

先研究 **10%光速飞船**，解锁小型战舰。在「发展」中安排人口，在「舰队」中生产武器、部署驻军。第 17 年会迎来第一次入侵，不要把全部经济耗在研究上。矿藏有限，及时发展其他星球；教育可降低逃亡主义。

文化达到 70 / 200 / 500 / 1000 时升级文明。全部异星文明结为亲密同盟或失去领土即胜利；失去全部己方领土、或逃亡主义达到 100 则失败。完整机制可在游戏内「百科」查阅。

| 操作                    | 控制                         |
| ----------------------- | ---------------------------- |
| 星图观察                | 拖动旋转、滚轮或双指缩放     |
| 选择天体                | 点击星球标签，或打开星球目录 |
| 切换面板                | `1`–`8`                      |
| 结束年度                | `N`                          |
| 切换声音                | `M`，默认静音                |
| 关闭辅助窗口 / 打开设置 | `Esc`                        |

**经典节奏**保留年度速度。**远征节奏**将科研、文化、设施施工与武器生产加速至三倍；经济、人口、敌方增长与剧情年份不变。两种节奏都包含重制版的人才征召等便利功能，并非旧程序的逐帧模拟。

### 存档

每次指令后自动保存，另有三个手动槽位以及 JSON 导入、导出。清理站点数据或更换浏览器会失去本地记录，请定期导出备份。旧版 `.lsv` 存档不兼容。隐私模式或禁用浏览器存储时，应使用 JSON 导出。

## 本地开发

需要 Node.js **22.12+** 与 npm。运行时不请求第三方字体、分析服务或远程 API。

```bash
npm ci
```

```bash
npm run dev
```

| 命令                   | 用途                               |
| ---------------------- | ---------------------------------- |
| `npm run check`        | TypeScript 严格检查                |
| `npm test`             | 规则、存档、种子世界与完整通关测试 |
| `npm run format:check` | 检查代码格式                       |
| `npm run format`       | 格式化源码与文档                   |
| `npm run build`        | 构建静态站点到 `dist/`             |
| `npm run preview`      | 预览生产构建                       |
| `npm run test:e2e`     | 桌面与移动端 Chromium 浏览器测试   |

首次运行浏览器测试前，先构建项目并安装 Chromium：

```bash
npx playwright install chromium
```

`src/game/` 是不依赖 DOM 的命令驱动引擎；`src/render/` 负责 Three.js 场景与音频；`src/ui/` 和 `src/styles/` 负责游戏 HUD；`src/content/` 保存内容与原作数据。游戏使用可复现的 32 位种子，规则测试包含外交与征服的完整通关路线。

### 原作数据导入

仓库已包含运行所需的数据和媒体，正常开发无需旧版安装包。重新导入需 Python 3、FFmpeg，以及自行取得的原始文件：

```bash
python3 scripts/extract-legacy.py /path/to/lengendofuni_src
```

```bash
python3 scripts/import-runtime.py /path/to/lou_game
```

脚本按 GB18030 解码原始文本，并记录输入文件的 SHA-256。运行时导入只处理 INI、图片、音乐和作者说明，不执行或复制旧版 EXE、DLL、安装器。不要直接编辑 `*.generated.json`；规则适配和扩展内容放在 TypeScript 中。

## 部署

GitHub Actions 在检查、单元测试、构建及桌面/移动端浏览器测试通过后，将 `dist/` 部署到 GitHub Pages。仓库 **Settings → Pages → Source** 应选择 **GitHub Actions**。构建使用相对资源路径，支持项目子目录部署。
